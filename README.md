## 🏛️ Design System: Swiss Editorial × Technical Bento

The visual architecture of `reitumetse.dev` is synthesized around **Swiss International Editorial dignity** paired with the **practical clarity of modern Bento modularity**:

* **Canvas Palette**: Warm non-glare architectural paper (`#F5F4EE`), deep espresso ink (`#151614`), British racing forest green (`#1E4A38`), and developer brand teal (`#00A389`).
* **Dark Mode Canvas**: Balanced obsidian charcoal (`#0C0E14`), soft ivory typography (`#ECEEF2`), radiant emerald (`#34D399`), and luminous teal (`#00DDB3`).
* **Typography Hierarchy**:
  * **Display & Editorial Titles**: `Instrument Serif` (Italic & Upright)
  * **Interface & Body Reading**: `Plus Jakarta Sans`
  * **Code, Metadata & Telemetry**: `JetBrains Mono`
* **Adaptive Navigation**:
  * **Desktop & Tablet (`md+`)**: Floating morphic liquid-glass capsule with the transparent brand **R** emblem, route tabs with active forest-green/emerald indicators, theme switcher, and direct Cal.com booking trigger.
  * **Mobile (`< md`)**: Touch-first floating capsule featuring the brand emblem, theme toggle, and an animated menu drawer with large tap targets and active indicators.
* **Independent Client Review Component**: Custom stepped-corner SVG-masked video component (`CreativeVideoMasking`) floating cleanly without artificial container boxes.

## 🛠️ Technical Stack & Toolchains

### Languages & Core Syntax
* **TypeScript** — Strict, type-safe development across the full stack.
* **Python** — Asynchronous backend services, data modeling, and scripting.
* **SQL (PostgreSQL)** — Relational schema architecture, migrations, and indexing.
* **HTML5 / Modern CSS** — Semantic markup, fluid typography, and design tokens.

### Frontend Engineering
* **Next.js 15 (App Router)** — React Server Components (RSC), Server Actions, and Partial Prerendering (PPR).
* **React 19** — Concurrent rendering, modern hooks, and optimistic UI updates.
* **Tailwind CSS v4** — Design-token utility engine.
* **Framer Motion** — Physics-based micro-interactions and transitions.
* **COBE** — Interactive, WebGL-rendered 3D rotating Earth globe.

### Backend & Database
* **FastAPI** — High-throughput asynchronous Python REST API framework.
* **PostgreSQL** — ACID-compliant relational database.
* **SQLAlchemy & Pydantic v2** — Type-safe ORM layers and runtime schema validation.
* **Webhooks & Async Events** — Real-time event handling and decoupled services.

### Cloud & Infrastructure
* **Railway** — Production container orchestration for FastAPI microservices and PostgreSQL.
* **Vercel** — Global edge network hosting Next.js frontend applications.
* **Cloudflare** — Edge caching, DNS management, and SSL/WAF protection.
* **Docker & Linux** — Environment isolation and continuous integration.

## 💻 Local Development

### Prerequisites
* **Node.js**: v20+ (tested on v24)
* **pnpm**: v10+
* **Python**: v3.10+ (for background tasks & FastAPI exploration)

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Allen-Reiley/portfolio.git
   cd portfolio/frontend
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Start the development server**:
   ```bash
   pnpm dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Production Build & Verification**:
   ```bash
   pnpm build
   pnpm start
   ```
